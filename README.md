## Atividade 1 - Teoria dos Conjuntos

**Arquivo:**
`P1/atividade_01_conjuntos/conjuntos.py`

O programa pede dois conjuntos ao usuário e realiza as operações solicitadas na atividade.

Para executar, abra o arquivo `conjuntos.py` e rode o programa pelo Python.

**Exemplo de entrada:**

```text
A: 1 2 3 4
B: 3 4 5 6
```

O programa mostra a união, interseção, diferenças, cardinalidades, conjunto das partes, uma partição, produto cartesiano e inclusão dos conjuntos.

## Atividade 2 - Divisibilidade, MDC e MMC

**Arquivo:**
`P1/atividade_02_divisibilidade/divisibilidade.py`

O programa pede dois números inteiros positivos.

Para executar, abra o arquivo `divisibilidade.py` e rode o programa pelo Python.

**Exemplo de entrada:**

```text
Primeiro número: 48
Segundo número: 18
```

O programa mostra a divisão inteira, o resto, o passo a passo do Algoritmo de Euclides, o MDC e o MMC.
